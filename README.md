## 🎯 Цель проекта

Этот проект — электронный учебник для изучения основ информатики. Он представляет собой десктопное приложение (WPF) с серверной частью, которое позволяет студентам изучать теорию, проходить тесты и отслеживать свой прогресс, а преподавателям — управлять контентом и просматривать результаты студентов.

Проект является результатом выполнения лабораторной работы №4 и демонстрирует навыки командной разработки и создания многослойных приложений.

## 🛠 Технологии и архитектура

**Стек:**
- **Клиент:** WPF (.NET 6) — десктопное приложение для студентов и преподавателей.
- **Сервер:** Web API на ASP.NET Core 6 — обработка запросов и бизнес-логика.
- **База данных:** Microsoft SQL Server 2019 — хранение данных.
- **ORM:** Entity Framework Core 6 — взаимодействие с БД.

**Архитектура:**
Проект построен по **клиент-серверной** модели с разделением на слои:
1.  **`InformaticsTextBook` (WPF-клиент)** — пользовательский интерфейс.
2.  **`ServiceLayer`** — бизнес-логика и репозитории для работы с БД.
3.  **`mybd.sql`** — скрипт инициализации структуры базы данных для SQL Server.

## ⚡️ Основной функционал

**Для студентов:**
- ✅ Изучение теоретического материала по информатике.
- ✅ Прохождение тестов и заданий.
- ✅ Просмотр своего прогресса и результатов.

**Для преподавателей:**
- ✅ Управление учебным контентом (добавление, редактирование материалов).
- ✅ Создание и редактирование тестов.
- ✅ Просмотр профилей студентов и их результатов.

**Общие возможности:**
- ✅ Авторизация и разграничение ролей (студент/преподаватель).
- ✅ Интуитивно понятный Windows-интерфейс.

## 🗄 База данных (Microsoft SQL Server)

Структура базы данных описана в файле `mybd.sql`. Основные сущности:
- `Users` — пользователи системы (студенты и преподаватели).
- `TheoryMaterials` — теоретические материалы по темам.
- `Tests` — тесты и вопросы.
- `TestResults` — результаты прохождения тестов студентами.

## 🚀 Как запустить локально

### 1. Клонируй репозиторий

```bash
git clone https://github.com/GSEvgenievich/LW4_InformaticsTextBook.git
cd LW4_InformaticsTextBook
```

### 2. Настрой базу данных (SQL Server)

- Установи **Microsoft SQL Server** (2012 или выше) и **SQL Server Management Studio (SSMS)**.
- Создай новую базу данных с именем `ispp2102` (или укажи свое имя).
- Открой файл `mybd.sql` и выполни его в созданной базе данных для создания всех таблиц и наполнения тестовыми данными.

### 3. Настрой и запусти проект

- Открой решение `LW4_InformaticsTextBook.sln` в **Visual Studio 2022**.
- Проверь строку подключения к БД в конфигурационном файле (обычно в `appsettings.json` или `App.config`). Убедись, что она указывает на твой сервер и созданную базу данных.
- Установи проект `InformaticsTextBook` (WPF-клиент) как стартовый и запусти его (нажми F5).
